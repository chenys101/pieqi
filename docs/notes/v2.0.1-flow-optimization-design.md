## 1. UI 交互（先于实现）

### 1.1 PC「新建需求」标题去箭头（→ ac3）

**现状**：`NewRequirementPage.vue` 标题行左侧**始终**渲染返回箭头；桌面侧栏已有导航时叠成「双返回」。

**目标交互**（对齐 Session 页「侧栏=导航、compact=移动返回」心智）：

| 视口 | 标题最左 |
|---|---|
| 桌面（非 compact / `md+`） | **不**渲染返回箭头；标题顶格 |
| 窄屏 / compact | **保留**返回箭头 → `/requirements`（或 `router.back` 有 history 时） |

**不做**：改需求详情页箭头；顺手改 `SessionHeader`（Session 桌面仍有箭头属既有行为，本票不扩）。

**实现落点**：仅 `web/src/pages/NewRequirementPage.vue`（+ 既有 ux/组件单测）。

### 1.2 需求详情「新建需求」快捷入口（→ ac6）

**现状**：详情页 header 仅有返回 / 标题 / 状态 /「标记完成」；新建需求在列表页与侧栏，详情内无入口。

**目标交互**：

```text
[←]  需求标题                    [状态]  [＋ 新建需求]  [标记完成?]
```

- 位置：详情 **header 操作区**（与「标记完成」同排），一眼可达。
- 点击 → `/requirements/new?project=<当前需求 project_path>`（与 `AppSidebar` / `NewTaskPage` 双入口约定一致，ADR-0021）。
- `project_path` 为空时仍可进新建页（query 省略），由新建页自身校验。
- **不要**在预览面板 / 正文区再复制一份入口。

**实现落点**：`RequirementPage.vue`（+ 页面/组件测：入口存在、query 正确）。

### 1.3 单 turn 免审 — 审批卡按钮（→ ac5，配合后端）

在现有审批卡可见动作上增加一档（仅 ACP 路径、`options` 声明后出现）：

| 按钮（建议文案） | choice | 作用域 |
|---|---|---|
| 允许 | `approve` | 仅本次 |
| 本轮同类免审 | `approve_turn` | **本 turn** 内同类（kind/配方规则同现网 session） |
| 本会话同类免审 | `approve_session` | 整段会话（**保留**，语义不变） |
| 拒绝 | `deny` | — |

**文案纪律**：必须让人分清「本轮」vs「本会话」；禁止把旧按钮改名却仍写 session 记忆。

**补偿**：`approve_same` 仍不可见；已 settled 再点「允许 / 本轮 / 本会话」时，前端改投逻辑与今日一致——补偿仍记 **session** 级（与「用户再点一次允许」兑现能力一致）；**不要**把 `approve_same` 改成 turn（否则补偿在轮末清空后无处兑现）。

L3 / 高危内联确认：对 `approve_turn` 与 `approve_session` 同等适用（不可逆操作仍二次确认）。

## 2. 单 turn 免审（后端判据 · → ac5）

### 2.1 与 `approve_session` 的关系

| 方案 | 结论 |
|---|---|
| 把 `approve_session` 改成 turn 作用域 | **否决**——破坏现网「本会话同类免审」心智与测试 |
| **新增 `approve_turn`** | **采纳** |

- `Decision.options`（ACP）：`approve` / `deny` / `approve_session` / **`approve_turn`**
- Claude hook 路径仍无 session/turn 同类选项（与今日一致）

### 2.2 唯一键与生命周期

```text
唯一键 = taskID（会话） + turnN
turnN  = CurrentTurnCount(events)   // EventUser 条数，1-based；ADR-0003
```

- 记忆结构：与 `sessionAlways` / `sessionRecipes` **同形**，另起 `turnAlways` / `turnRecipes`（名可调整，语义必须是 turn 作用域）。
- **写入**：用户选择 `approve_turn` 且 adapter 放行成功后（纪律同 `approve_session`：失败不记账）。
- **命中**：`tryAutoApprove` 在查 session 记忆之外，查当前 turn 记忆；命中则自动放行。
- **清除**（任一即清，清后本会话该 turn 记忆作废）：
  1. 新 `EventUser` 到达（下一 turn 起点，`Resume` / 续问路径已有 `clearStaleDecision` 附近）；
  2. 本轮进入终态转换（`completeTask` / `failTask` / `cancelled`）时；
  3. `Unwire` / 会话销毁（与 session 记忆一并消失）。
- **不落盘**；短时内存 only。

### 2.3 日志（可检索）

凡经 **turn 记忆**自动放行，必须打 Info 级日志，字段至少：

| 字段 | 例 |
|---|---|
| task | taskID |
| turn | turnN |
| tool / kind / recipe | 与现有 auto-pass 风格对齐 |
| via | `turn`（相对 session / settings / l0l1） |

便于与 `approval settled` / session auto-pass 对照。单测断言日志或可观测 hook（与 `agent_perm_test` 风格一致）。

### 2.4 硬边界（不得放宽）

与 ADR-0015 / `kindSessionRememberable` / TrustedRecipes 规范化**同一套**：

- 所有删除；工作区外写；`git push`；改基线；
- 宽泛 `execute` **不**整类记入 turnAlways（只记配方，与 session 纪律一致）。

## 3. `settings.json` 启动初始化（→ ac4）

### 3.1 现状 vs 目标

| | 现状 | 目标 |
|---|---|---|
| 文件缺失 | `NewSettingsStore` 用内存 `DefaultSettings()`，**首次 Patch 才落盘** | 启动时若 `PIEQI_HOME/settings.json`（或配置的 path）**不存在** → **原子写入**初始化文件 |
| 文件损坏 | 报错，不静默覆盖 | **保持**（不得改为静默重置） |
| 空文件 | 今日当默认 | 可视为缺失并初始化，或保持默认不落盘；**推荐：与缺失同等落盘**，避免「半存在」 |

### 3.2 首落盘字段表

以 `DefaultSettings()` + `SetFallbackProjectPath` 生效后的内存态为准写入：

| JSON 键 | 首落盘值 | 来源 | 备注 |
|---|---|---|---|
| `auto_approve_l0` | `true` | `DefaultSettings` | |
| `auto_approve_l1` | `true` | 同上 | |
| `auto_approve_local_execute` | `false`（零值） | 结构体零值 | 可省略或显式 false；推荐**显式写出**便于人读 |
| `dnd_enabled` | `false` | Default | |
| `dnd_start` | `"22:00"` | Default | |
| `dnd_end` | `"08:00"` | Default | |
| `event_retention` | `5000` | Default | |
| `default_project_path` | `<dataRoot>/workspace` | `SetFallbackProjectPath` 注入后 | **必须有键**；空串仅在用户显式清空后出现 |
| `trusted_recipes` | 省略或 `[]` | 空 = 不额外放行 L2 | 空切片与省略语义：加载后均为「无额外配方」 |
| `agents` | 省略或 `{}` | `Enabled` nil = 对接列表全选 | 启停/排序走设置页；空 = 全选 |

### 3.3 硬约束

1. **显式清空 `default_project_path`（键在、值为 `""`）不得被 fallback 回填**  
   —— 既有 `projectPathSet` / `TestSettings_DefaultProjectPath_ExplicitClearSticks` 纪律；初始化落盘不得破坏这条。
2. 初始化写入必须在 `SetFallbackProjectPath` **之后**（或写入前已能算到 fallback），否则首文件会缺项目路径或写上空串误标「显式」。
3. Windows：**`.tmp` + `rename`** 原子写（仓库既有 settings 落盘路径）。
4. `path == ""`（纯内存测试 store）**不**强制落盘。

### 3.4 Agents / TrustedRecipes 语义备忘（实现勿走样）

- `agents.enabled`：**nil / 空切片 = 对接列表全选**（清空≠「一个都没有」）；数组序 = 选择器展示序。
- `trusted_recipes`：空 = 不额外放行；规范化拒绝硬边界命令。

## 4. 软完成 / 该审必见（摘要 · → ac1 / ac2）

详见 [`approval-miss-and-soft-complete.md`](./approval-miss-and-soft-complete.md)。一句话：

- **终态**：中断 → `failed` + `approval unresolved` / `tool hung without result`；**不**引入 `interrupted` / `finish_reason`。
- **P1 露出**：当前会话卡必见；非当前会话待办计数。
- **附录**空文案 / 超时早感知 / Cursor 抖动 / 额度：**不进本需求 AC**。

## 7. 明确不做（本需求总表）

- 新 `TaskStatus=interrupted` / `finish_reason`
- 缩短默认审批超时；未弹卡自动 approve；plan 作完成闸门
- 空审批文案专项、超时早感知专项
- Cursor 连接抖动 / 额度耗尽人读面
- 扩大 L2/L3 免审；改 hook 路径强行加 approve_session/turn
- 把 `approve_session` 降级为 turn
- Web IDE / 非目标清单项（ADR-0007）
