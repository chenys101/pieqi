**R8 验收标准（AC，逐条可判定）**

1. 详情页与新建任务页的输入条与正文**左右边界对齐**（容器同为 `max-w-3xl` + 同 padding），在 **1280 / 768 / 375** 三档实测像素一致。
2. 输入框底色浅色取 `--surface-subtle`；**深色主题下呈"浮起"而非"凹陷"**（明度方向符合 SPEC §3.2）。
3. 聚焦时可见 **3px accent ring**；Tab 可聚焦，焦点可见性达 AA。
4. 发送 / 创建按钮**命中区 ≥ 44×44px**（视觉可为 36，用伪元素扩命中）。
